Installation

Get Started in Minutes

1

Download the Extension

Click the Download v1.0.1 button above to get the .zip file from GitHub Releases.

2

Extract the ZIP File

Unzip the downloaded file to a folder you'll remember. Keep it somewhere permanent — don't delete it after installation.

3

Open Chrome Extensions

Navigate to chrome://extensions in your Chrome address bar and enable Developer mode using the toggle in the top-right corner.

4

Load Unpacked Extension

Click "Load unpacked" and select the folder you extracted in Step 2. The extension icon should appear in your toolbar.

5

Start Downloading

Visit any video page on cinemana.shabakaty.com and the download button will appear automatically. Enjoy offline viewing!
