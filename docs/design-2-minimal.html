Installation

Up and running in under a minute

1

Download the extension

Click the download button above to get the .zip file, or download directly from the GitHub releases page.

2

Extract the files

Unzip the downloaded file to a folder on your computer. Remember where you saved it.

3

Load in Chrome

Open chrome://extensions, enable Developer Mode, click "Load unpacked", and select the extracted folder.

4

Start downloading

Visit cinemana.shabakaty.com. The download button will appear on video pages automatically.
